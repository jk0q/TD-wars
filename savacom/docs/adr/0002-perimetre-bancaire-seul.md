# Le périmètre de l'intervention est le flux bancaire ; les factures fournisseurs font l'objet d'une offre distincte

Le brief de mission couvre deux chantiers — convertir les exports bancaires en
écritures, et extraire les données des factures fournisseurs pour les renommer
et les archiver — sous un plafond de dix heures. Nous n'en retenons qu'un : le
flux bancaire. Les factures fournisseurs seront chiffrées séparément.

## Pourquoi

Les deux chantiers n'ont presque rien en commun. Le bancaire est un travail de
format, largement abouti, qui donne une victoire vérifiable le jour même : un
import qui passe, ça se constate. Les factures fournisseurs sont un chantier
entier — reconnaissance du fournisseur, TVA multi-taux, nomenclature,
archivage, traitement des cas douteux — et c'est précisément ce que faisait
Multigest. Les entamer en fin de journée produirait une démonstration, pas un
système, et créerait l'attente que le plus dur est fait alors qu'il commence.

## Conséquences

- Le critère de réussite de l'intervention est un import bancaire réellement
  validé dans WinBiz, pas un « zero-touch » complet.
- L'attente doit être recadrée auprès du client avant l'intervention, pas
  pendant.
